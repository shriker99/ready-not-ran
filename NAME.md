# Product name

**Store name:** Really Ran

**Line:** Windows said Ready. Did it really run?

**Why this one:** NightProof is already a different product. Ready ≠ Ran is clever but hard to say and hard to type. Really Ran is the same idea in two words.

**What we did not change**

- GitHub folder: `ready-not-ran` (old download links still work)
- Files on disk: `ReadyNotRan.ps1` and `%LOCALAPPDATA%\ReadyNotRan` (so spare copies and Undo still find them)

**What the client sees**

- Desktop: **Really Ran** and **Fix the easy ones**
- Start Menu folder: Really Ran
- Reports and the download page use Really Ran
