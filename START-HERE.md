# Start here

You do not need to be a computer person.

Windows has a night to-do list: backups, file copies, reports. It often puts a green check next to those jobs and says they are Ready. That check can mean “I started,” not “the work finished.”

## Do this

1. Unzip the download.
2. Double-click **Install.cmd**.
3. If Windows asks, click **More info**, then **Run anyway**.
4. On the Desktop, double-click **Ready Not Ran**.
5. Open the report it creates (a page in your browser).
6. Read the red and yellow rows first. Ignore green until those are clear.

## What the colors mean

- **Red (Failed)** — Windows tried. The work did not finish.
- **Yellow (Missed / Never ran)** — The clock time passed, or it has never run.
- **Blue (May skip)** — It looks fine, but a setting can quietly skip it (sleep, battery, nobody signed in).
- **Green (Looks OK)** — No obvious trap. Still glance at the folder where the backup or report should appear.

## What this will not do

It will not break your files. The checker only looks. If you later press a Fix button, it asks first and keeps a spare copy so you can undo.

If you get stuck, hand the report and **BUYERS.md** to whoever looks after the PC.
