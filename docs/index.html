Ready ≠ Ran
Any Windows 10 or 11 PC

Did last night’s backup actually finish?

Windows often puts a green check next to night work and says it is Ready. That check can mean “I started,” not “the files are safe.” This tool is for shop owners, home offices, and anyone who is not an IT person.

Download Ready ≠ Ran

Free. Unzip the folder. Double-click Install.cmd. No tech talk required. Nothing leaves your PC.

1 · Download

Get the folder. Same download on every PC.

2 · Install

One double-click puts a shortcut on the Desktop.

3 · Check

It reads the night to-do list and opens a simple report. Red and yellow first.

4 · Fix only if you want

You can leave it at looking. If you fix a setting, it asks first and keeps a spare copy so you can undo.

What it can tell you, in plain English

  • The backup never ran because the laptop was on battery
  • The PC was asleep and nobody woke it
  • It only runs while someone is signed in — so nights are skipped
  • Last week’s missed night was never tried again
  • The saved password went stale after you changed the Windows password
  • The file was supposed to land on a drive letter that is not there at night

It does not change the program a job runs. It does not need your name. If Windows shows a blue warning, click More info, then Run anyway.
