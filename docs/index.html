Ready ≠ Ran
Windows 10 / 11

Windows says the night job is Ready. That often only means it started.

Download the pack. Install it for this Windows user. Scan. Then flip the settings that quietly skip backups, exports, and reports — or leave them alone.

Download Ready ≠ Ran

Free ZIP. Unzip → double-click Install.cmd. No administrator account. Nothing leaves the PC.

1 · Download

Get the ZIP. Same file on every PC.

2 · Install

Install.cmd copies it into this user’s AppData and puts a shortcut on the Desktop.

3 · Scan

The app looks for 28 traps. Red and yellow first.

4 · Fix if you want

Tick the settings. Confirm. A backup XML is saved so you can Undo.

What you can change in the app

  • Allow the job on battery, or keep wall-power only
  • Keep running if the plug is pulled
  • Wake the PC for the night slot
  • Catch up after a missed night
  • Stop waiting for the PC to sit idle
  • Retry after a fail
  • Un-hide a job
  • Include or hide Microsoft’s own jobs

The app does not change the program a job runs. It does not send a name, email, or PC model anywhere. Open every script in Notepad first if you want.
